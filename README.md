## 国内为什么订不了，代充是怎么绕的

Google One 官方帮助页列出的可订阅国家和地区有一百九十多个，中国大陆和香港都不在里面。付款环节同样走不通：Google Pay 不支持国内发行的银行卡，双币卡也常被拒，官方渠道不收支付宝和微信。

代充平台的做法，基本都落在同一个机制上——**Google One 家庭组共享**。由订阅方把一个已付费的 Ultra 名额共享给家庭成员，你的账号以家庭成员身份获得权益。

围绕这个机制，市面上能买到的东西分成几种，权利差别很大：

1. **自己的账号 + 家庭组邀请**。文件、邮件、聊天记录都留在自己号里，你只需要点一下接受邀请。这是风险最低的一种。
2. **成品号**。给你邮箱、密码、恢复邮箱或 2FA 密钥。便宜、即时，但账号不归你，卖家随时可能改动或回收。
3. **家庭组车主**。给你一个带家庭组管理权限的账号，你可以自己再拉 4 个人分摊成本。
4. **租号**。一个号只卖给你一个人，但通常明确禁止改密码、改恢复信息、共享或转卖，违规会直接终止权限且不退款。
5. **拼车 / 车队**。几个人凑一个家庭组，成本最低，不确定性也最高。

> 几乎所有走家庭组的路子都有一条硬约束：不能退出、不能被移出家庭组。一旦离开家庭组，Gemini 权益立刻消失，而且普遍不在质保范围内。转售渠道另外常写明的还有：不包含 YouTube Premium；禁止 API、自动化脚本、代理、爬虫、CLI 和非官方扩展；未发货前取消订单约收 25% 手续费，交付或激活之后不退款。

拼车的成本可以算得很清楚。2026 年 3 月社区里一份公开整理的算法是：官价 $250、首三个月半价、汇率按 7 算，5 人车个人成本约 ¥175–180，6 人车约 ¥146–150；同期的闲鱼 5 人车普遍卖到 ¥260 以上。那份资料同时点出了三个现实限制——反代和 OAuth 登录极易封号、乘客账号一年只能更换一次家庭组、半价期一过车主通常会换号，乘客得跟着换。

## 下单前的检查清单

- 你要的是**自己的账号**还是别人的号？能用自己号走家庭组邀请的，优先这一种。
- 卖家要不要你的 Gmail 密码？如果你能自己点接受邀请，正常流程不需要密码。
- 是否明确说明走 Google One 家庭组？如果是，就要接受"退出即失效"这条规则。
- 质保覆盖什么、不覆盖什么？Google 安全验证、手机号验证、判定违规、功能变更、服务中断，多数渠道都不保。
- 到期前两三天开始盯续费状态，别等到弹回免费版才找客服。
- 不要用反代、OAuth 第三方登录、API 或自动化脚本，这是封号高发区，且基本不受质保保护。
- 不确定稳不稳，先买最短周期，别一上来就压三个月。
